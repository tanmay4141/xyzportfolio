# Tanmay Kumar — Portfolio

Personal portfolio site for **Tanmay Kumar** (JECRC University).

## Stack

- React + TypeScript
- Vite
- Responsive sidebar layout with forest theme

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## GitHub Pages

This project uses `base: "/portfolio/"` for deployment at:
